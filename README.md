# Blue Archive Cafe Layout Simulator

ブルーアーカイブのカフェ家具配置を確認する非公式シミュレータです。

## GitHub Pages

このリポジトリは `outputs` フォルダを GitHub Pages に公開する設定です。

1. GitHubで新しいリポジトリを作成します。
2. このフォルダを `main` ブランチとしてpushします。
3. GitHubのリポジトリ設定で `Settings` -> `Pages` を開きます。
4. `Build and deployment` の `Source` を `GitHub Actions` にします。
5. `Actions` の `Deploy to GitHub Pages` が完了すると公開URLが表示されます。

公開されるトップページは `outputs/index.html` です。
